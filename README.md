# 💳 Python ATM Simulator

An interactive ATM simulation application built using core Python logic and Streamlit web interface.

## ✨ Features
* PIN Authentication: 3-attempt security limit before card block.
* Balance Inquiries: Real-time account balance tracking.
* Safe Withdrawals: Enforces minimum account threshold of ₹500.
* Instant Deposits: Live balance updates with validation.

## 🚀 How to Run Locally
Ensure Streamlit is installed:
`bash
pip install streamlit
python -m streamlit run app.py
